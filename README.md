# PDF 편집기

브라우저에서 PDF를 열고 편집하는 웹 앱입니다. **파일이 서버로 전송되지 않고 100% 브라우저 안에서 처리됩니다.**

https://stepersjmj-hash.github.io/pdf/

## 기능

- **열기/보기** — 드래그 앤 드롭 또는 파일 선택, 섬네일 목록, 확대/축소
- **페이지 편집** — 삭제, 회전(90°), 드래그로 순서 변경
- **병합** — 다른 PDF를 뒤에 추가
- **추출(분할)** — 체크한 페이지만 새 PDF로 다운로드
- **주석** — 텍스트(한글 지원, Noto Sans KR 임베딩), 형광펜, 사각형 → 저장 시 PDF에 병합됨
- **텍스트 검색** — `Ctrl+F` 또는 🔍 버튼, 전체 페이지 검색·하이라이트·결과 간 이동
- **인쇄** — `Ctrl+P` 또는 🖨️ 버튼, 편집·주석이 반영된 상태로 인쇄
- **암호 보호 PDF 열기** — 열 때 암호를 입력하면 보기·편집 가능.
  저장 시 원본 품질(벡터·텍스트) 그대로 유지되며, 결과물은 암호 없이 열립니다
- **암호 걸어 저장** — 🔒 버튼으로 암호(AES-256)를 설정해 다운로드.
  암호를 아는 사람만 열 수 있습니다

## 기술 스택

| 역할 | 라이브러리 |
|---|---|
| 렌더링(보기) | [pdf.js](https://mozilla.github.io/pdf.js/) (`pdfjs-dist`) |
| 편집/저장 | [pdf-lib](https://pdf-lib.js.org/) + `@pdf-lib/fontkit` |
| 번들러 | Vite |

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # dist/ 에 정적 파일 생성 → 아무 정적 호스팅에 배포 가능
```

## 구조

- `index.html` — 레이아웃 (상단 바, 툴바, 섬네일 사이드바, 뷰어)
- `src/main.js` — 앱 전체 로직 (상태, 렌더링, 주석, 저장)
- `src/style.css` — 스타일
- `public/fonts/NotoSansKR-Regular.otf` — 한글 텍스트 주석용 폰트 (저장 시 서브셋 임베딩)

### 좌표 변환 메모

주석은 "회전이 반영된 표시 화면" 기준 비율 좌표(fx, fy)로 저장되고,
저장 시 `displayToPdf()`가 페이지 회전값(0/90/180/270)에 따라 PDF 사용자 좌표(좌하단 원점)로 역변환합니다.
페이지를 회전하면 `transformAnnosForRotation()`이 기존 주석 좌표도 함께 회전시킵니다.
